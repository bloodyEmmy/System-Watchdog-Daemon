# System Watchdog Daemon

Сервис для фонового мониторинга аппаратных ресурсов (CPU, RAM, Disk, LA) и анализа логов в системах Linux. Демон собирает метрики, выявляет аномалии и отправляет уведомления через системный журнал syslog.

## Требования
1. Установленный Python 3.
2. Пакетный менеджер pip.
3. Права суперпользователя (sudo) для установки системного сервиса.

## Установка
1. Клонируйте репозиторий и перейдите в папку проекта.
2. Установите необходимые зависимости:
```
pip install -r requirements.txt
```
3. Выдайте права на исполнение bash-скриптам:
```
chmod +x install.sh control.sh
```
4. Запустите скрипт установки (создаст systemd сервис и пропишет пути):
```
sudo ./install.sh
```

## Управление сервисом
Используйте скрипт `control.sh` для управления демоном:
1. Запуск демона и добавление в автозагрузку:
```
./control.sh start
```
2. Остановка демона и удаление из автозагрузки:
```
./control.sh stop
```
3. Проверка текущего статуса:
```
./control.sh status
```

## Чтение логов
Все метрики и алерты отправляются в системный журнал. Для просмотра логов в реальном времени выполните команду:
```
journalctl -u watchdog.service -f
```
